# Global Public Health Lens · Information Architecture

Phase 1 locks the navigation vocabulary and gives every primary destination a canonical URL. The homepage is an editorial entry point; it no longer repeats every content section in one long scroll.

## Primary navigation

```text
Brand / Home

About ▾
  Our Mission        /about/mission
  Our Team           /about/team

Country Spotlight    /country-spotlight

The Lens ▾
  Micronutrients     /lens/micronutrients
  How the Lens Works /lens/how-it-works
  Solutions & Action /lens/solutions

Nutrition App        /nutrition-app
Contact              /contact
```

`Evidence Base` is a canonical footer utility destination at `/evidence-base`. It is intentionally not duplicated in the primary header. `Explore the Map` is not a second navigation item; Country Spotlight is the single map destination.

## Layout translation from the Allbareun reference

- The homepage establishes the project and routes people into the work through an editorial directory.
- Each destination is a separate page with a breadcrumb, one clear content section, and the shared footer.
- Page sections retain the existing wide content rhythm, hairline rules, and section-specific compositions. Repeated card grids are not used as a universal template.
- Grouped navigation uses visible disclosure buttons on desktop and mobile. Hover, focus, click, active-route styling, and keyboard escape/focus return communicate interaction.
